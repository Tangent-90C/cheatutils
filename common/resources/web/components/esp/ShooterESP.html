Boxes players who fired a TaCZ gun while the game was not drawing them.
A shot is audible whenever the shooter is inside the server tracking range, which is a purely horizontal test - it ignores terrain and chunk state. Rendering additionally requires the entity to be inside the vanilla entity render distance (~128 blocks for a player) and to survive the view frustum and occlusion culling. Shooters that are audible but invisible sit in that gap, and this module boxes them at their real position.
TaCZ has to be installed for the module to see anything.
