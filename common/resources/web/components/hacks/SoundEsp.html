Marks positions of sounds received from the server (gunshots, footsteps, etc.) with Entity-ESP style boxes and tracers. Color = sound category (players / hostile / neutral / blocks / voice). Green box = player entity spawned on the client. Sound markers appearing before the green box of the same player indicate server-side entity spawn delay. All events are also logged to sound_debug/*.csv in the game directory for offline lag analysis.
