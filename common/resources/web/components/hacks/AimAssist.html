Aim Correction
Slowly rotates your crosshair toward the closest valid entity to the look vector. Rotation is limited by Rotation Speed, so it never snaps to the target and you can override it with your own mouse movement.

To make it activate only while a key is held, use Event Scripting to toggle the runtime switch. This does not change the saved config, so the checkbox stays on and the key just gates it: input.isMouseDown takes the raw GLFW button number: 0 is left, 1 is right, 2 is middle, and 3 and 4 are the two side buttons. Use input.isKeyDown for a keyboard key instead. Aim Correction also has to stay enabled above, the key only acts as an additional gate.
Aim At
Auto Head Center Feet
Which part of the hitbox to aim at.
Auto - aims at whatever point of the hitbox is closest to your crosshair.
Head - aims at the target's eyes.
Center - aims at the middle of the hitbox.
Feet - aims at the bottom of the hitbox.

The selected point is only a preference. If a block covers it, Aim Correction falls back to another exposed part instead of dropping the target, so partially visible entities are still attackable.
Range:
Maximum distance to a target. Default: 128
Rotation Speed:
Degrees per second the crosshair is allowed to rotate. Default: 600
FOV:
Only entities inside this cone around your crosshair are considered. Set to 360 to disable the limit. Default: 120
Precision:
Stop correcting once the crosshair is this many degrees away from the target, which prevents jitter around the aim point. Default: 0.1

Aim While Blocking
Filter Teammates
Skips players identified as teammates by scoreboard team or identical glowing color. Servers usually make teammates glow, so two equally glowing players count as a team.
Combat Mode
Automatically presses the attack key once Aim Correction is close enough to the aim point. Requires Aim Correction to be enabled.
Warning: while a block instead of an entity is under the crosshair, Combat Mode still triggers the attack key and can break blocks. Turn it off while mining.
Click Hold
Click - repeatedly clicks at "Clicks per second".
Hold - holds the attack button for fully automatic weapons.
Clicks per second:
Attack frequency in Click mode. Values below 1 are allowed for slow weapons. Default: 10
First attack delay:
Milliseconds to wait after the crosshair reaches the aim point before the first click. Set to 0 for no delay. Default: 0
Attack tolerance:
Maximum angular error at which Combat Mode is allowed to attack. Default: 1
Debug Logging
Writes Aim Correction diagnostics to the console and latest.log once per second, including how many entities were rejected and why. Useful when a target is not being picked up.
