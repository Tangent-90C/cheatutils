Sync Shoot Origin In The Air
TaCZ spawns bullets from the position the gun was drawn at, and only refreshes that origin when a gun is drawn. After flying, falling or travelling far the bullets keep spawning from the old spot, so every shot misses no matter how well you aim. With this option on, flying more than 2 blocks from the last synced position re-sends a draw to the server, which re-snapshots the origin at your current position.

Each sync costs the gun's put-away time (about 0.43s for the default SCAR-L) before the next shot goes through, so syncing happens while you reposition - at most once per 1.5 seconds - and never while you are holding fire. Hover in place after a reposition and shots keep flying uninterrupted and on target.

Automatic Bullet Calibration
Learns the current TaCZ weapon's muzzle speed, drag, and gravity from your own bullet trajectories. Uses the manual Bullet speed while warming up.
Use Local Gun Data
Reads installed TaCZ gun packs from the game's tacz folder and from mods jars (TaCZ ships its default gun pack inside its own mod jar). Local data takes priority over learned data.
Calibration HUD
Shows the current weapon, effective ballistic parameters, sample count, and calibration state on screen.
Debug Logging
Logs calibration decisions to the game log. Very verbose.
Manual Fallback
