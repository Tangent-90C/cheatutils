Removes TaCZ gun recoil while a gun is held in the main hand.
Enabled
How It Works
TaCZ applies recoil by writing the player's rotation once per frame while following a time-based recoil curve, both as a camera kick and as a real rotation change that the server sees. This module snapshots the rotation at the start of every camera setup and restores it at the end of the same frame:
  • the camera stays perfectly still while firing,
  • the rotation sent to the server never contains the recoil, so bullets fly exactly where the crosshair points,
  • it stays active while aiming down sights, and works together with TacZ Aim Assist (its aim is snapshotted, not reverted).
Only applies while the main-hand item is recognized as a TaCZ gun.
