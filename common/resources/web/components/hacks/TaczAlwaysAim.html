Makes every TaCZ shot use the AIM accuracy stance, no matter how you move or where you are.
Enabled
What It Does
TaCZ picks the bullet spread from your stance: AIM while the aim animation is complete, otherwise LIE, SNEAK, MOVE (any movement, including jumping) or STAND. Those values differ a lot - for the default SCAR-L the AIM stance is 0.125° while standing is 5° and moving is 5.5°.

The stance is decided on the server from the aiming state the client reports. While this module is enabled the aim key is reported as held, so the server keeps you in the AIM stance all the time:
  • every shot uses the AIM spread, in the air, while moving, hip-fired, anywhere;
  • your own aim key still works - press it and the view zooms as usual;
  • releasing the aim key no longer drops you out of the AIM stance.
Movement
Don't Affect Movement
While aiming TaCZ applies a movement-speed penalty (the gun's aim multiplier, -15% for the default SCAR-L) as an attribute modifier on the server, which syncs the slower value to the client. With this option the modifier is removed locally every tick, so you move at full speed.

The server keeps its own copy of the modifier. Vanilla movement checks are far more tolerant than a 15% difference, but a server with a custom anti-cheat that compares your movement against its attributes can still notice the mismatch. Sprinting is recomputed from your input every tick, so it is not affected either way.
