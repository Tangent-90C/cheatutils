Controls how recoil affects your shot. The view hold pulls the camera back to where you aimed before the frame is rendered; the CSMC hooks reshape the predicted bullet direction on top of that.
Enabled
Mode:
Dead aim: crosshair locked, everything hits the crosshair - no recoil compensation at all.
View kick: the crosshair climbs with recoil as usual, but impacts group on the original point.
Locked legacy: crosshair locked with the old behaviour - the stream pins but not all bullets land on one point.
View hold, %: (dead aim / locked legacy only; 100 = fully fixed)
Send Clean Rotation
Also sends the aimed-at rotation instead of the recoil-affected one, so the server sees the same direction you see. Expect up to one frame of aim lag, because the value comes from the last rendered frame.
